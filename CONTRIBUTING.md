# Guide de Contribution

Merci de votre intérêt pour contribuer à notre projet DCGAN ! Voici quelques lignes directrices pour faciliter votre contribution.

## Comment Contribuer

1. **Fork & Clone**
   - Créez un fork du projet
   - Clonez votre fork localement

2. **Branches**
   - Créez une branche pour chaque nouvelle fonctionnalité ou correction
   - Utilisez des noms descriptifs pour vos branches (ex: `feature/amelioration-discriminateur`)

3. **Commits**
   - Écrivez des messages de commit clairs et descriptifs
   - Format recommandé : `type(scope): description`
   - Types : feat, fix, docs, style, refactor, test, chore

4. **Tests**
   - Ajoutez des tests pour les nouvelles fonctionnalités
   - Assurez-vous que tous les tests passent

5. **Documentation**
   - Mettez à jour la documentation si nécessaire
   - Commentez votre code de manière claire

## Style de Code

- Suivez PEP 8 pour le code Python
- Utilisez des noms de variables et fonctions descriptifs
- Commentez les sections complexes du code
- Limitez la longueur des lignes à 79 caractères

## Processus de Pull Request

1. Mettez à jour votre branche avec la dernière version de main
2. Testez vos modifications
3. Créez une Pull Request avec une description claire
4. Attendez la review et répondez aux commentaires

## Signalement de Bugs

- Utilisez le système d'issues de GitHub
- Incluez les étapes pour reproduire le bug
- Mentionnez votre environnement (OS, version Python, etc.)

## Questions

Pour toute question, n'hésitez pas à ouvrir une issue avec le tag 'question'.

Merci de contribuer à l'amélioration de ce projet !
